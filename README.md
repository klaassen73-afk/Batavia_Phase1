# Batavia_Phase1

Review mockups for the Batavia Container website refresh, Phase 1 (Pinnacle Advertising).

- `index.html`: review board
- `live/homepage-reskin.html`: homepage, option 1 (new logo, footer, announcement bar)
- `live/homepage-option2.html`: homepage, option 2 (adds the brand popup; `?popup` always opens it)
- `live/brand-evolution.html`: the new "Our New Brand" page
- `assets/morph/`: BCI → Batavia logo morph (After Effects render)

The homepage pages are a snapshot of the live bataviacontainer.com with Phase 1 changes applied; analytics are stripped.
This is not the live site and is kept out of search engines (`robots.txt` + `X-Robots-Tag: noindex`).

Built and published from the project folder with `mockups/publish.sh`.
